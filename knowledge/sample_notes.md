## 数学 - 一元二次方程
- 一般形式：ax² + bx + c = 0（a ≠ 0）
- 求根公式：x = [-b ± √(b² - 4ac)] / (2a)
- 判别式 Δ = b² - 4ac：
  - Δ > 0：两个不相等实根
  - Δ = 0：两个相等实根
  - Δ < 0：无实根（有共轭复根）
- 韦达定理：x₁ + x₂ = -b/a，x₁ · x₂ = c/a

## 物理 - 牛顿第二定律
- 公式：F = ma
- F：合外力（牛顿 N）
- m：质量（千克 kg）
- a：加速度（m/s²）
- 注意：F 是物体所受的合外力，不是某一个力
